# analyse-ventes-python

Ce projet est un mini-projet d’analyse de données réalisé avec Python. Il a pour but de pratiquer les étapes de manipulation, nettoyage et visualisation de données à partir d’un fichier de ventes.

## 🗂 Contenu du projet

- `main.py` : Script principal contenant le code Python d’analyse des données
- `data/sales.csv` : Jeu de données utilisé pour l’analyse
- `requirements.txt` : Liste des bibliothèques Python nécessaires
- `README.md` : Ce fichier de présentation du projet

## 🔧 Librairies utilisées

- `pandas` : Manipulation de données
- `matplotlib` : Visualisation graphique
- `seaborn` : Visualisation avancée

Tu peux les installer avec :

```bash
pip install -r requirements.txt
